# Portfolio v2 — дизайн-система

## Статус и происхождение

Это визуальный источник истины для реализации Portfolio v2. Система сохраняет работающую editorial/terminal-идею текущего сайта и уточняет её с учётом PDT, accessibility и коммерческого сценария.

Автоматический поиск UI-направлений подтвердил пригодность заметной сетки, контрастной editorial-подачи, просторного ритма и умеренной асимметрии. Случайные рекомендации, противоречащие PDT — тёмная OLED-тема, FAQ-паттерн и розовая палитра — отклонены.

**Design dials:** variance 6/10, motion 3/10, density 3/10.

## Характер

- Светлый editorial-интерфейс с техническими terminal-деталями.
- Уверенный и спокойный, без визуальной агрессии и «хакерских» клише.
- Крупная типографика, видимые границы, точечная сетка, один яркий CTA.
- Асимметрия используется для иерархии, а не ради декора.

| Дополнительный фон | `#F1EAD9` | `--paper-2` |

| Фиолетовый акцент | `#5B3DF5` | `--violet` |
| Тёмный фиолетовый | `#2F1FB8` | `--violet-deep` |

Лаймовый цвет не используется для мелкого текста на светлом фоне. Основной CTA — тёмный фон и светлый текст; лайм работает как маркер и вспомогательный акцент.

## Типографика

- Display: `Fraunces`, variable serif — только для крупных заголовков и выразительных чисел.
- Interface/body: `JetBrains Mono`, monospace — текст, навигация, метки, кнопки.
- Body: минимум 16 px, line-height не менее 1.5.
- Мелкие служебные метки: минимум 12 px, повышенный letter-spacing допустим только при коротких строках.
- Заголовки балансируются по строкам; одиночные слова в последней строке избегаются.

Контейнер: максимум 1120 px с боковыми полями 20 px mobile, 32 px tablet и 40 px desktop.

## Геометрия

- Карточки: radius 20–28 px.
- Кнопки и chips: pill-форма допустима.
- Границы: 1 px для структуры, 2 px для активных акцентов.
- Тени используются редко; предпочтительнее граница и цветовая плоскость.
- Фото остаётся круглым или получает мягкую editorial-рамку без тяжёлых эффектов.

## Компоненты

### Навигация

- Семантический `nav`, короткие якоря: услуги, проекты, процесс, контакт.
- На mobile не создавать скрытое меню, пока пункты помещаются в компактную строку; при нехватке места показывать основной CTA и доступную альтернативную навигацию.
- При фиксированном header каждый anchor получает scroll margin.

### Кнопки

- Минимальная зона 44×44 px.
- Primary: `--ink` / `--paper`, заметный hover без сдвига layout.
- Secondary: прозрачный фон, видимая граница.
- Focus-visible: контрастное кольцо минимум 3 px с offset.

### Карточки

- Карточка не считается кликабельной, если внутри нет реальной ссылки.
- Hover не является единственным способом увидеть информацию.
- Проектная карточка содержит задачу, решение, роль, стек и статус в DOM-порядке.

### Статусы

- Цвет всегда сопровождается текстом.
- Метка не переносится внутри короткого статуса; длинный статус переносится целиком без обрезки.

## Движение

- 180–240 ms для hover/focus, easing `cubic-bezier(0.2, 0.8, 0.2, 1)`.
- Появление контента: opacity + translateY не более 12 px, 300–400 ms.
- Никакого scroll-jacking, parallax или обязательной scroll-анимации.
- При `prefers-reduced-motion: reduce` контент сразу находится в финальном состоянии.

## Адаптивность

Обязательные контрольные ширины: 320, 375, 768, 1024 и 1440 px.

- Mobile-first CSS.
- Никакой горизонтальной прокрутки.
- Сетки переходят в одну колонку до того, как карточки становятся уже читаемого минимума.
- Длинные технологии и URL переносятся безопасно.
- Основной CTA виден в первом экране на 375×812 без перекрытия контента.

## Accessibility

- Контраст обычного текста минимум 4.5:1.
- Сохраняется логичный порядок заголовков и landmarks.
- Skip-link — первый фокусируемый элемент.
- Все интерактивные элементы доступны с клавиатуры.
- Декоративные элементы скрыты от accessibility tree.
- `aria-label` не дублирует видимый текст без причины.
- Изображения имеют осмысленный alt или пустой alt для декора.

## Запрещённые паттерны

- Неподтверждённые цифры, логотипы клиентов и показатели.
- Emoji в роли интерфейсных иконок.
- Невидимые focus-состояния.
- Мелкий серый текст на кремовом фоне.
- Масштабирование карточек, вызывающее layout shift.
- Сложная клиентская анимация и новая dependency без доказанной пользы.
- Контент, который становится доступен только после выполнения JavaScript.

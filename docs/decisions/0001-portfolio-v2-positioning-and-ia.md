# ADR-0001: коммерческое позиционирование и одностраничная IA Portfolio v2

## Статус

Accepted

## Дата

2026-09-15

## Контекст

Текущий сайт визуально передаёт IT/AI-характер и показывает реальные проекты, но первый экран представляет автора как «начинающего» и концентрируется на процессе обучения. Для заказчика это увеличивает воспринимаемый риск и не отвечает быстро на вопросы: какие задачи можно поручить, какой будет результат и почему исполнителю можно доверять.

Одновременно сайт должен оставаться честным: проекты находятся на разных стадиях, публичные результаты и коммерческие метрики ограничены.

## Решение

Позиционировать Андрея как специалиста по веб-разработке и AI-автоматизации через типы решаемых задач, не используя уровень «начинающий» как главное сообщение.

Сохранить одностраничный формат и выстроить блоки по коммерческому пути: Hero → услуги → проекты → процесс → инженерный подход → контакт → footer.

Доверие формировать через точные статусы, структуру кейсов, GitHub, проверяемый процесс и прозрачные ограничения. Неподтверждённые цифры и статусы не публиковать.

## Рассмотренные альтернативы

### Сохранить текущую визитку

Плюсы: не требует переработки. Минусы: слабое предложение услуг и недостаточно доказательств для заказчика. Отклонено.

### Сделать многостраничное агентское портфолио

Плюсы: больше места для SEO и кейсов. Минусы: объём контента пока не оправдывает сложность; увеличиваются сроки и стоимость поддержки. Отложено до появления подтверждённых подробных кейсов.

### Полностью сменить визуальную систему

Плюсы: можно начать без ограничений текущей реализации. Минусы: теряется уже работающая узнаваемость и растёт риск бесконечного редизайна. Отклонено для v2.

## Последствия

- Основной интерфейс остаётся одностраничным и пригодным для GitHub Pages.
- Текущая визуальная идея сохраняется, но компоненты и контент будут перестроены.
- Проекты требуют дополнительной фактологической проверки перед публикацией расширенных кейсов.
- Реализация разбивается на Engineering Packs, чтобы изменения оставались проверяемыми и обратимыми.
- Аналитика, отдельные страницы кейсов и смена хостинга требуют новых решений.

# Публикация во ВКонтакте через официальный API

Дата подготовки: 28 октября 2026 года.

## Цели

- приложение VK ID: `APP_ID=54862985`;
- личная страница Андрея: `owner_id=45791512`;
- группа «СпецТехника76»: `owner_id=-242185483`;
- публикация возможна отдельно или сразу в обе цели;
- реальная отправка разрешена только после просмотра текста, файлов и кода
  проверенного черновика.

## Безопасность

- токен VK не записывается в файлы проекта и не передаётся в чат;
- локальные `.env*` исключены из Git;
- журнал успешных публикаций хранится в `var/vk-publications.jsonl` и также
  исключён из Git;
- команда `publish` требует код, рассчитанный по тексту, изображениям и цели;
- изменение любого элемента делает прежний код недействительным.

## Подключение

1. Создать приложение в кабинете VK ID и получить `APP_ID`.
2. Авторизовать пользователя `45791512` через OAuth 2.1 с разрешениями,
   достаточными для работы со стеной и фотографиями. Пользователь должен
   оставаться администратором группы `242185483`.
3. Сохранить полученный пользовательский токен только в локальной переменной
   окружения `VK_ACCESS_TOKEN`.
4. При необходимости задать `VK_API_VERSION`; по умолчанию используется
   `5.199`.

Приложение создано: `APP_ID=54862985`. Для доверенного адреса возврата
подготовлена техническая страница:

`https://bav56172-svg.github.io/andrey-portfolio/vk-auth/`

Она считывает одноразовые параметры OAuth из адресной строки только в браузере,
ничего не отправляет на сервер портфолио и удаляет параметры из строки после
копирования. До отдельного подтверждения эта страница остаётся только локальным
изменением и не публикуется.

Пример локальной сессии терминала:

```sh
export VK_ACCESS_TOKEN='значение вводится только локально'
```

## Предпросмотр

Личная страница:

```sh
npm run vk:preview -- content/vk/profile-intro.json --target=profile
```

Группа:

```sh
npm run vk:preview -- content/vk/spec76-group-intro.json --target=group
```

Обе цели:

```sh
npm run vk:preview -- content/vk/profile-intro.json --target=both
```

Предпросмотр ничего не отправляет и выводит код проверенного черновика.

## Публикация

После отдельного подтверждения владельца повторить команду с тем же файлом,
целью и кодом:

```sh
npm run vk:publish -- content/vk/profile-intro.json --target=profile --approval=КОД
```

Инструмент загружает изображения через `photos.getWallUploadServer` и
`photos.saveWallPhoto`, создаёт запись методом `wall.post`, затем сохраняет
полученную ссылку в локальный журнал.

Закрепление, редактирование и удаление записей намеренно не автоматизированы:
для них требуется отдельное подтверждение и отдельная команда.

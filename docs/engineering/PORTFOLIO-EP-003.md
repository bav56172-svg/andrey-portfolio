# PORTFOLIO-EP-003: Hero, навигация и услуги

## Статус

In review

## Цель

Реализовать первый коммерческий сценарий Portfolio v2: пользователь сразу понимает специализацию, видит набор услуг и может перейти к обсуждению проекта.

## В scope

- доступная header-навигация и skip-link;
- новое позиционирование и тексты Hero из PDT;
- основной и вторичный CTA;
- адаптивный портрет и terminal-акцент;
- четыре направления услуг;
- единая визуальная основа для следующих секций;
- актуальные metadata title/description.

Существующие проекты и Telegram-контакт сохранены в целостном интерфейсе; доказательная структура кейсов выполняется в EP-004.

## Критерии приёмки

- [x] `npm run check` проходит.
- [x] Изображение фактически загружается в браузере.
- [x] CTA виден в первом экране на 320×812 и 375×812.
- [x] На 320, 375, 768, 1024 и 1440 px нет обрезанного контента или горизонтального overflow.
- [x] H1/H2/H3 образуют последовательную структуру.
- [x] Browser console не содержит error или warning.
- [x] `prefers-reduced-motion` отключает несущественное движение.
- [x] Ветка отправлена, PR #3 создан, GitHub quality check завершён успешно.

## Исправления по результатам UI-проверки

1. Desktop CTA был ниже первого экрана при высоте 720 px — Hero уплотнён.
2. Mobile-портрет находился перед предложением и отодвигал CTA — восстановлен смысловой DOM-порядок.
3. Grid min-content обрезал Hero на 375 px — контентной колонке задан `min-width: 0`.
4. Доступный текст H1 склеивал слова на границе вложенного `span` — добавлен явный пробел.

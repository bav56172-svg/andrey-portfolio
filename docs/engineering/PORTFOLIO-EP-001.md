# PORTFOLIO-EP-001: позиционирование, IA и документация

## Статус

In review

## Цель

Создать проверенный baseline и единый письменный источник истины для Portfolio v2 до изменения пользовательского интерфейса.

## В scope

- безопасная проверка и создание единственного локального клона;
- инвентаризация исходного проекта и Git/GitHub;
- фиксация продуктовой цели, позиционирования и информационной архитектуры;
- готовые тексты экранов;
- правила дальнейших Engineering Pack;
- ADR по ключевому направлению продукта;
- README и журнал изменений.

## Вне scope

- изменение визуального интерфейса;
- обновление зависимостей;
- изменение GitHub Pages;
- публикация новой версии сайта;
- добавление неподтверждённых фактов о проектах или исполнителе.

## Артефакты

- `README.md`
- `docs/product/portfolio-v2-pdt.md`
- `docs/inventory/baseline-2026-09-15.md`
- `docs/engineering/README.md`
- `docs/decisions/0001-portfolio-v2-positioning-and-ia.md`
- `CHANGELOG.md`

## Критерии приёмки

- [x] Baseline commit и структура проекта записаны.
- [x] Текущий build проверен без сохранения сгенерированных изменений.
- [x] Риски dependency audit записаны без автоматического major-upgrade.
- [x] Позиционирование и порядок экранов определены.
- [x] Для каждого экрана подготовлены тексты и назначение.
- [x] Правила Engineering Pack и дальнейшая последовательность определены.
- [ ] Ветка отправлена в GitHub.
- [ ] PR создан и фактически доступен.
- [ ] Проверки PR завершены.
